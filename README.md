# Fluxora - Gestão Comercial e PDV 📦

Bem-vindo ao repositório oficial de distribuição do **Fluxora**. 

Este espaço é utilizado exclusivamente para a hospedagem e disponibilização das versões de instalação do sistema de gestão comercial e ponto de venda (ERP/PDV). O código-fonte da aplicação é mantido num ambiente privado.

## 📥 Como descarregar (Download)

Para obter a versão mais recente do sistema:
1. Aceda ao separador **[Releases](../../releases/latest)** localizado na barra lateral direita desta página.
2. Na secção **Assets**, clique no ficheiro `.zip` (ex: `Fluxora-Setup-1.0.8-win-x64-UNSIGNED-DEV.zip`) para iniciar o download.
3. Extraia o conteúdo da pasta compactada no seu computador.

## ⚙️ Instalação e Avisos de Segurança

Como esta é uma versão de distribuição em desenvolvimento e o instalador ainda não possui um certificado digital assinado, o Windows pode apresentar um ecrã azul de proteção (SmartScreen) a informar que "o Windows protegeu o seu PC". 

Para prosseguir com a instalação em segurança:
1. Clique em **"Mais informações"** no ecrã azul.
2. Em seguida, clique no botão **"Executar mesmo assim"**.

## 💻 Requisitos do Sistema
- **Sistema Operativo:** Windows 10 ou Windows 11 (64 bits).
- **Dependências:** .NET 10 Desktop Runtime.
- **Base de Dados:** Requer conexão com o SQL Server (local ou remoto) para o funcionamento da retaguarda de cadastros, stocks e finanças.
